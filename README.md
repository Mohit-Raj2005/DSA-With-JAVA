# 📘 DSA-With-JAVA

A comprehensive collection of **Data Structures and Algorithms (DSA)** implemented in **Java**.  
This repository is built for **learning, interview preparation, and coding practice**, with clean and well-structured code examples.

---

## 🚀 Features
- ✅ Covers **fundamental data structures**: Arrays, Strings, Linked Lists, Stacks, Queues, Trees, Graphs  
- ✅ Includes **classic algorithms**: Sorting, Searching, Recursion, Dynamic Programming  
- ✅ Well-commented and beginner-friendly implementations  
- ✅ Organized solutions for **LeetCode-style problems**  
- ✅ Great resource for **interview prep** and **academic learning**

---
## 📈 Complexity Cheat Sheet

Here’s a quick reference for the time and space complexities of common data structures and algorithms implemented in this repository:

| Data Structure / Algorithm | Time Complexity (Average) | Time Complexity (Worst) | Space Complexity |
|-----------------------------|---------------------------|--------------------------|------------------|
| Array Access               | O(1)                      | O(1)                     | O(n)             |
| Array Search (Linear)      | O(n)                      | O(n)                     | O(1)             |
| Binary Search              | O(log n)                  | O(log n)                 | O(1)             |
| Linked List Insertion      | O(1)                      | O(1)                     | O(n)             |
| Linked List Search         | O(n)                      | O(n)                     | O(n)             |
| Stack Push/Pop             | O(1)                      | O(1)                     | O(n)             |
| Queue Enqueue/Dequeue      | O(1)                      | O(1)                     | O(n)             |
| Merge Sort                 | O(n log n)                | O(n log n)               | O(n)             |
| Quick Sort                 | O(n log n)                | O(n²)                    | O(log n)         |
| BFS (Graph)                | O(V + E)                  | O(V + E)                 | O(V + E)         |
| DFS (Graph)                | O(V + E)                  | O(V + E)                 | O(V + E)         |
| Dynamic Programming (Fibonacci) | O(n)                 | O(n)                     | O(n)             |

> **Note:**  
> - `V` = number of vertices  
> - `E` = number of edges  
> - Complexities may vary slightly depending on implementation details.
